# เว็บเครื่องมือจัดการไฟล์ PDF เบื้องต้น (Client-Side PDF Tools)

เว็บแอปพลิเคชันสำหรับโครงงานมหาวิทยาลัย จัดการไฟล์ PDF เบื้องต้นผ่านเบราว์เซอร์

ลิงก์ทดสอบการใช้งาน : https://pdf-web-tools-kbu.vercel.app/

---

## รายละเอียดด้านความปลอดภัยและความเป็นส่วนตัว

1. **เว็ปไซต์จะประมวลผลบนเบราว์เซอร์ทั้งหมด (Client-Side):** ไม่ใช้ backend หรือ server ใดๆ ทั้งสิ้น
2. **ห้ามส่งไฟล์ออกนอกเครื่องเด็ดขาด:** ไฟล์ที่ผู้ใช้เลือกจะไม่ถูกอัปโหลดหรือส่งออกจากเครื่องไปยังเซิร์ฟเวอร์หรือบริการภายนอกใดๆ
3. **ไม่มีระบบบันทึกสถิติ:** ไม่มีการติดตั้ง Tracker หรือ Analytics ภายนอกที่อาจส่งข้อมูลผู้ใช้ออกไป
4. **โฮสต์เป็น Static Site ได้:** สามารถโฮสต์บน Cloudflare Pages, Vercel หรือ Netlify ได้โดยตรง

---

## วิธีการติดตั้งและรันโปรเจกต์

### 1. ติดตั้ง Dependencies
```bash
npm install
```

### 2. รันในโหมดพัฒนา (Development Server)
```bash
npm run dev
```

### 3. ตรวจสอบโค้ด (Linting)
```bash
npm run lint
```

### 4. สร้าง Static Build สำหรับ Deploy
```bash
npm run build
```
ไฟล์สำหรับขึ้นโฮสต์จะอยู่ในโฟลเดอร์ `dist/` สามารถนำไป deploy บน Cloudflare Pages, Netlify หรือ Vercel ได้

---

## เครื่องมือทั้ง 6 ฟีเจอร์ (อย่างอื่นๆกำลังอยู่ในช่วงพัฒนาอยู่)
- **Combine (ผสานไฟล์):** รวมไฟล์ PDF หลายไฟล์เป็นไฟล์เดียว
- **Organize (จัดหน้า):** หมุนหน้า สลับลำดับ และลบหน้าที่ไม่ต้องการ
- **Create (สร้าง PDF):** สร้างเอกสาร PDF จากรูปภาพ หรือพิมพ์ข้อความ
- **Export (ส่งออก):** แปลงหน้า PDF เป็นภาพ (PNG/JPG) หรือแปลงเป็นข้อความ (.txt)
- **Add comments (ใส่ข้อความ):** แปะโน้ตหรือข้อความกำกับบนหน้า PDF
- **Protect (ใส่รหัสผ่าน):** เข้ารหัสล็อกไฟล์ด้วยมาตรฐาน
